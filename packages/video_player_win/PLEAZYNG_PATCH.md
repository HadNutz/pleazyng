The Dart controller and Windows Flutter plugin come from Jakky's [video_player_win 3.3.1](https://pub.dev/packages/video_player_win/versions/3.3.1) under the included BSD 3-Clause license.

Pleazyng exposes Media Foundation audio streams and in-band timed text on the existing player channel. The callbacks and selection state belong to the individual texture's media engine. The native plugin uses the Windows SDK's WRL smart pointers throughout.
