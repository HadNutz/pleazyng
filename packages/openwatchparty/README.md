# OpenWatchParty Dart SDK

This directory vendors [OpenWatchParty 1.1.0](https://pub.dev/packages/openwatchparty/versions/1.1.0), authored upstream by [@edde746](https://github.com/edde746) under the included Apache-2.0 license. [Upstream source](https://github.com/edde746/openwatchparty/tree/main/sdk/dart).

Pleazyng adds an authenticated cold-reconnect entry point and access to the active membership checkpoint. Admission, server confirmation, member identity and clock synchronization continue through the SDK’s reconnect flow. The application encrypts the checkpoint and binds it to the original profile and relay.
