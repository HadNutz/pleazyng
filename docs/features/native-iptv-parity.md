# Native IPTV implementation status

Pleazyng implements these workflows in its own app. [M3U Web Picker v49](https://github.com/zschmook/m3u-web-picker/tree/8822e68538ac91ab25bf805a74fa6bacdc2b7897) by [Zachary Schmook](https://github.com/zschmook) and contributors is the behavioral reference. The comparison below uses that revision. The native implementation and test fixtures are original to Pleazyng.

| Workflow | Available in Pleazyng | Open parity work |
| --- | --- | --- |
| Source setup | Live TV source settings accept an M3U URL, file or pasted playlist, Xtream credentials, and an optional base URL. The IPTV-org U.S. preview pre-fills a real public source. File replacement validates before replacing the encrypted copy. | Resumable multi-stage onboarding and qualification at the upstream defaults of 50,000 channels and 96 MiB per provider. |
| Channel curation | Manage Channels searches station names, numbers, group names and guide IDs. The editor supports exact group filtering, bulk visibility, explicit order, and overlapping named groups. Hiding the provider’s LOW BANDWIDTH group in the editor leaves saved selections intact. Conflicting group, bulk visibility and order edits can be retried after reload. | Household edit synchronization, cross-source published lineups, and independent receiver validation. |
| Feed fallback | Select backup sources in the primary source editor. Live session recovery opens a matching channel using the backup’s own credentials and headers. Conflicting station IDs, ambiguous names, hidden channels and locked backup channels are excluded. | Background health and capacity probes, persistent last-known-good routing, and protected-route enforcement. |
| Guide and files | Earlier configured XMLTV sources take precedence over the whole airing interval. Export the current visible, unlocked selection as M3U or XMLTV from Manage Channels. Direct M3U export includes the actual stream addresses. A Stalker portal’s dynamically issued playback links require a running session and support guide-only file export. | Country-guide affiliate aliases, online publication, stable virtual tuner URLs, event artwork, and browser/receiver parity. |
| Sports | Live TV → Sports groups concrete two-team fixtures listed in the next three days, offers matching visible feeds, opens the ordinary programme guide, and stores followed teams per profile. | League, conference and sport subscriptions, official schedules, provider-only events, alternate kickoff times, generated stations, maps, replay controls and sports scoreboards. |
| Recording | From an IPTV programme’s details, Record Series adds a rule on that station. Guide refreshes reconcile recurring airings into the on-device scheduler. Episode IDs and season/episode markers prevent duplicate captures. With no episode identity, the scheduler uses the original UTC time slot with a 90-minute tolerance across midnight. Removing a rule in Recordings removes its pending captures and preserves active captures and one-off timers. | Unattended household scheduling, recording conflicts and padding, commercial detection, conversion, retention and delivery. |
| Library television | Existing library playback remains available through Pleazyng. | Native TV/movie channel builders, scheduling, interstitials, shared broadcast clock and private movie controls. |
| Household operation | Existing Live TV playback, casting and phone remote remain available through their normal entry points. | Packaged always-on runtime, session-based media delivery, tuner discovery, browser guide, Roku receiver, physical lighting, WireGuard supervision, diagnostics, backups, installers and upgrades. |

On tvOS, a small encrypted local playlist and its lineup can survive database cache eviction through the existing identity recovery store. If that store would exceed its bounded preferences budget, Pleazyng retains the source configuration and requests the original playlist again after cache loss. The authoritative SQLite copy continues to work while present.

## Qualification

The regression suites cover import and replacement, overlapping guide windows, distinct signed feeds, bulk edits, stale orders, overlapping groups, exports, profile isolation, backup-stream headers, guide-listed doubleheaders and replay exclusion, scheduling, and tvOS cache recovery. Release-level comparisons still require deterministic fixtures against the pinned reference and runs on each supported receiver and host class. Physical devices, household media workers, and native installation and recovery must pass before advertising full parity.
